# Contributing to Rindle

The repository is a minimal Rust CLI scaffold. Product commands have not been defined yet; contributions should keep the CLI surface focused and add tests for new behavior.

## Prerequisites

- Rust from `rust-toolchain.toml` (currently 1.99.1)
- `just`
- Bun for the documentation site
- `cargo-dist` 0.32.0 only when inspecting or changing release configuration

## Development and tests

```bash
just check-fast
just check
just build
./target/debug/rindle --help
```

The full checks cover formatting, Clippy warnings, and tests. Application behavior belongs in `src/`; update tests and user-facing docs alongside it.

## Documentation

```bash
just docs-install
just docs-test
just docs-check
just docs-dev
```

The docs live in `docs/` with Astro and ZueDocs. GitHub Actions deploys changed docs to Vercel from `main`; unrelated Rust commits do not request a deployment. Keep `docs/vercel.json` configured with `git.deploymentEnabled: false` and no `ignoreCommand` to avoid duplicated, quota-consuming deployments.

## Distribution

Rindle uses direct GitHub Releases, without npm publishing or a Mac menu bar app. `dist-workspace.toml` is maintained source; `.github/workflows/release.yml` is generated by `dist generate`. Follow `.agents/skills/release/SKILL.md` when preparing a release. Do not tag a release until an actual command set is implemented, validated, and documented.
